
# Cafe Maka
Cafe Maka es una plataforma web y sistema de ventas diseñado para posicionar la marca en el mercado. Este proyecto no solo funciona como un e-commerce para la venta de nuestro café, sino que también es un espacio dedicado a compartir nuestra historia, conectar con la comunidad y enseñar las mejores recetas para aprovechar nuestros productos al máximo.

# CARACTERISTICAS PRINCIPALES:

# Catalogo de Productos: 
Exploración y compra del mejor café con un sistema de carrito interactivo.

# Nuestra Historia: 
Una sección dedicada a mostrar el origen, la misión y la visión detrás de Cafe Maka.

# Recetario Exclusivo: 
Guías y preparaciones paso a paso para que los clientes aprendan a usar y disfrutar nuestro café en casa.

# Sistema de Ventas: 
Flujo de compra optimizado para una excelente experiencia de usuario.

# REQUISITOS PREVIOS:
Asegúrate de tener instalado en tu computadora Node.js (incluye npm, que es necesario para instalar y correr el proyecto).

# INSTALACION Y EJECUCION:
Sigue estos pasos para levantar el entorno de desarrollo en tu máquina local:

# Paso 1: 
Clona este repositorio en tu computadora usando el comando: git clone URL_DEL_REPOSITORIO

# Paso 2: 
Navega a la carpeta del proyecto con el comando: cd Front_Maka

# Paso 3: 
Instala las dependencias necesarias con el comando: npm install

# Paso 4: 
Ejecuta el servidor de desarrollo con el comando: npm run dev

# Paso 5: 
En tu consola aparecerá una dirección URL. Cópiala y pégala en tu navegador web de preferencia para ver la página en funcionamiento.
