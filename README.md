
# Cafe Maka
Cafe Maka es una plataforma web y sistema de ventas diseñado para posicionar la marca en el mercado. Este proyecto no solo funciona como un e-commerce para la venta de nuestro café, sino que también es un espacio dedicado a compartir nuestra historia, conectar con la comunidad y enseñar las mejores recetas para aprovechar nuestros productos al máximo.
